# Plateforme de reservation de salles

Application pedagogique de gestion des salles d'un centre de formation.

## Environnement

- Node.js 20 ou superieur
- Aucun paquet externe necessaire

## Lancement

Depuis le dossier du projet :

```bash
npm start
```

Ouvrir ensuite http://localhost:3000

## API disponible

- GET /api/health
- GET /api/rooms
- GET /api/reservations

## Donnees

Les donnees de demonstration sont stockees dans le dossier data.

## Evolutions attendues

sont a definir et a realiser dans le cadre du sujet d'evaluation.
